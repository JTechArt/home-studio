# Project Vision

Home Studio is a modern web application created for a small custom furniture workshop based in Gyumri, Armenia.

The workshop specializes in designing and manufacturing custom furniture using MDF, laminated boards, and other modern materials. Their work includes kitchens, wardrobes, bedrooms, TV units, office furniture, children's rooms, and other custom interior solutions.

The purpose of the website is not to sell ready-made furniture, but to present completed projects, inspire potential customers, and make it easy for them to contact the workshop.

Instead of a traditional online shop, the website will function as a digital portfolio.

Each completed project will be organized into categories and assigned a unique project code. Customers can browse the gallery and later refer to a project code when requesting a similar design with different dimensions, colors, or materials.

Example:

"We like project KIT-024, but we'd like it in matte black with oak accents."

This approach simplifies communication and helps the workshop quickly identify previous work.

The public website should be clean, modern, and image-focused. Large, high-quality photographs will be the primary content. Text should remain minimal, allowing the completed projects to speak for themselves.

The website should feel more like an interior design studio than a furniture factory. The emphasis is on craftsmanship, custom solutions, and thoughtful design rather than mass production.

An administrative dashboard will allow workshop staff to manage all portfolio content without technical knowledge.

The admin panel will support:

- Secure login
- Project management
- Category management
- Image uploads
- Cover image selection
- Project codes
- Visibility control
- Basic statistics

Projects may contain multiple images but will not have dedicated detail pages. Selecting a project from the gallery will open a lightbox where visitors can browse all associated photos and view the project code.

Initially, the website will support categories such as:

- Kitchens
- Wardrobes
- Bedrooms
- Living Rooms
- TV Units
- Office Furniture
- Children's Rooms
- Custom Projects

Future versions may include online quote requests, material catalogs, color selectors, project videos, multilingual support, and customer appointment scheduling.

The visual identity should be minimal and modern. Neutral colors, generous spacing, and elegant typography will keep attention on the furniture itself.

The working name for the project is Home Studio. The name may change later, but the overall concept of a friendly, local design workshop should remain the foundation of the brand.
