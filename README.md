# Home Studio

Custom furniture portfolio website for a workshop in Gyumri, Armenia.

## Architecture

- **Backend**: Spring Boot 3.x, Java 21, PostgreSQL, JWT Auth
- **Frontend**: React 19 + Vite + TypeScript (Noir Atelier design)
- **Infrastructure**: Docker, Nginx, GitHub Actions → Hetzner

## Development

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Full Stack (Docker)
```bash
docker compose up --build
```
